# Ninja Date Invite

A playful, interactive date invitation with a customizable date planner.

[![Open the website](https://img.shields.io/badge/Website-Open%20Live%20Site-ff3366?style=for-the-badge)](https://kaizen02403x.github.io/ninja-date-invite-v2/)

## Run locally

Open `index.html` in a browser, or start a local server from this directory:

```sh
python3 -m http.server 8080
```

Then visit <http://localhost:8080>.

The live site is published with GitHub Pages. Each push to `main` deploys the site.
